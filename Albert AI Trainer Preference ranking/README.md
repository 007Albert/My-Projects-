# Project 2: AI Response Preference Ranking

## Purpose
Practise comparing two candidate AI responses, choosing the better fit for the prompt, and explaining the decision using consistent criteria.

## Files
- `data/preference_ranking_dataset.csv` — 20 labelled examples with rationales.
- `docs/preference_ranking_guidelines.md` — ranking criteria and workflow.
- `docs/project_report.md` — project overview, method, findings, and limitations.
- `YOUR_BLIND_RANKING_WORKSHEET.md` — worksheet for completing the rankings independently.

## How to complete the project
1. Open the CSV in Excel or Google Sheets.
2. Hide the reference columns (`preferred_response`, `primary_reason`, `review_note`).
3. Complete the blind-ranking worksheet before revealing the reference choices.
4. Compare your judgments to the sample judgments.
5. Review every disagreement and record whether the difference came from a factual check, a missed instruction, or a reasonable close call.
6. Keep this work labelled as an independent practice project.

## Skills demonstrated
- Pairwise response comparison
- Instruction-following evaluation
- Factual and logical error detection
- Safety-aware evaluation
- Evidence-based written justification
- Handling ambiguous or close decisions

## Important limitation
The dataset uses synthetic examples and illustrative reference judgments. It is a learning artifact, not evidence of paid AI training experience or verified agreement with professional annotators.
