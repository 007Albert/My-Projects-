# AI Trainer Portfolio — Practice Projects

**Focus:** AI response evaluation, preference ranking, text annotation, and Python-based evaluation.

This portfolio contains four independent practice projects designed to demonstrate foundational AI training skills. The datasets and examples are synthetic and educational; they are not paid client work or evidence of employment.

## Projects

### 1. AI Response Evaluation
Score model responses for accuracy, relevance, instruction following, clarity, and completeness; explain issues and write corrections.
- Dataset: `01_ai_response_evaluation/evaluation_dataset.csv`
- Guidelines: `01_ai_response_evaluation/evaluation_guidelines.md`

### 2. AI Preference Ranking
Compare two responses, choose the better answer for the prompt, and justify the preference.
- Dataset: `02_preference_ranking/preference_ranking_dataset.csv`
- Guidelines: `02_preference_ranking/ranking_guidelines.md`

### 3. Sentiment Data Annotation
Classify 100 synthetic text samples as Positive, Negative, Neutral, or Mixed.
- Dataset: `03_data_annotation/sentiment_annotation_dataset.csv`
- Guidelines: `03_data_annotation/annotation_guidelines.md`

### 4. Python AI Evaluation Tool
A no-dependency Python command-line script that validates evaluation scores, summarizes criterion averages, and flags low-accuracy responses.
- Code: `04_python_evaluation_tool/evaluate_responses.py`
- Usage: `04_python_evaluation_tool/README.md`

## How to use this portfolio
1. Review the guidelines before looking at the labels or scores.
2. Re-evaluate a subset independently and compare your reasoning with the sample annotations.
3. Add a short reflection explaining any changes you made and why.
4. Replace or expand synthetic examples with your own original examples.
5. Publish the repository on GitHub only after reviewing every example and ensuring you can explain your decisions.

## Important limitations
- All included samples are synthetic practice data.
- Scores and labels are illustrative and should be critically reviewed.
- The Python tool summarizes entered scores; it does not itself verify truth or judge response quality.
- Do not add confidential employer data or restricted platform task material.
